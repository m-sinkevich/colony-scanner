⚙ НАСТРОЙКИ СКАНЕРОВ

Применяются ко всем телефонам при следующем «ОБНОВИТЬ ⟳». «Как на телефоне» — настройка не задана отсюда, у каждого телефона остаётся своя (из служебного меню).

После изменений игроки нажимают «ОБНОВИТЬ ⟳» внизу экрана сканера (нужен интернет). Без обновления у них остаётся прежняя база.

КОД МЕТКИПРОФИЛЬКАРТИНКАЗАГОЛОВОК / ТЕКСТ

Профиль — тип прибора у игрока. ID — короткое латинское имя, оно указывается в метках. Менять ID у профиля, который уже используется, не стоит — записи меток перестанут к нему относиться.

IDНАЗВАНИЕЦВЕТПОДПИСЬПОРЯДОКВКЛ
Как узнать код метки. На телефоне со сканером удерживайте заголовок 3 секунды → PIN мастера → служебное меню. Поднесите метку: появится её UID (например 04A2B3C4D5E680). Его и вписывайте в поле «Код метки».

Одна метка — разные профили. Создайте несколько записей с одним кодом: медик увидит одно, техник другое. Профиль «* любой» показывается всем, у кого нет своей записи для этой метки.

Картинки загружаются в хранилище Supabase (бакет content-media, папка scanner/). Лучше JPG/PNG шириной до 1000 px.

Выключенная запись (галочка «Активна» снята) не попадает на телефоны при следующем обновлении.

Если панель пишет об отсутствии таблиц — выполните supabase.sql из репозитория colony-scanner в SQL Editor Supabase.
