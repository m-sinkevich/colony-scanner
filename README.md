# Сканер — NFC-приложение для ролевой игры

Телефон игрока работает как прибор (медицинский, технический и т.д.). Игрок подносит телефон к объекту
с NFC-меткой, на экране идёт анимация анализа, затем показывается текст и картинка, которые мастера
заранее занесли в базу для кода этой метки. На игре интернет не нужен: база с картинками скачивается заранее.

## Установка

1. Скачайте `colony-scanner.apk` со страницы **Releases → latest** этого репозитория.
2. Откройте файл на телефоне и разрешите установку из этого источника.
3. Включите NFC в настройках телефона.

Новые сборки ставятся поверх старых, база при этом сохраняется.

## Как играть

- При первом запуске игрок выбирает профиль сканера. Сменить его позже может только мастер.
- Поднесите заднюю часть телефона к метке (обычно NFC-антенна в центре или у камеры) и подержите 1–2 секунды.
- Или нажмите «Сканировать»: 3–4 секунды идёт поиск, за это время нужно поднести телефон к метке.
- Возможные результаты:
  - **Объект идентифицирован** — показывается запись из базы.
  - **Анализ невозможен** — метка есть в базе, но не для этого профиля (например, техник сканирует пациента).
  - **Объект не опознан** — кода метки нет в базе.

## Подготовка базы (мастерам)

1. В Supabase откройте **SQL Editor**, вставьте содержимое `supabase.sql` и нажмите **Run**.
   Будут созданы таблицы `scan_modes` и `scan_tags`, а также публичный бакет `scan-images` для картинок.
2. **Профили** — таблица `scan_modes`: `id` (латиница, например `medic`), название, цвет, подпись.
3. **Метки** — таблица `scan_tags`, одна строка на пару «метка + профиль»:
   - `code` — код метки (см. ниже);
   - `scanner` — `id` профиля, или `*`, если запись показывается любому сканеру;
   - `title`, `body` — заголовок и текст (переносы строк сохраняются);
   - `image_url` — имя файла в бакете `scan-images` (например `patients/ivan.jpg`) или полная ссылка;
   - `active = false` — временно скрыть запись.

   Одна и та же метка может выдавать разное разным профилям: заведите несколько строк с одним `code`
   и разными `scanner`. Если для профиля нет строки, но есть строка с `*`, показывается она.
4. **Картинки** загрузите в Storage → `scan-images`. Лучше JPG или PNG шириной до 1000 px.

### Какой код у метки

Удерживайте заголовок «СКАНЕР // …» 3 секунды и введите PIN мастера (по умолчанию **1234**).
В служебном меню поднесите метку — появятся её коды:

- **UID** — заводской номер метки. Ничего записывать на метку не нужно, просто скопируйте его в `code`.
- **Текст** — если вы записали на метку текстовую запись (например, приложением NFC Tools),
  можно использовать её как код: `MED-01`, `GEN-12` и т.п. Так удобнее — метку легко заменить, записав на новую тот же текст.

Регистр, пробелы, двоеточия и дефисы в кодах не важны: `04:a2:b3` и `04A2B3` совпадут.

## Настройка телефонов

1. Служебное меню → **Сервер Supabase**: вставьте Project URL и публичный ключ
   (Project Settings → API: `anon` или `publishable`). Нажмите «Сохранить и загрузить базу».
2. После загрузки телефон работает без интернета. Перед игрой или после правок базы
   нажмите внизу главного экрана «обновить ⟳».
3. В служебном меню можно сменить профиль игрока и PIN.

Чтобы не вводить адрес и ключ на каждом телефоне, добавьте в репозиторий секреты
`SUPABASE_URL`, `SUPABASE_KEY` и при желании `MASTER_PIN`
(Settings → Secrets and variables → Actions) и перезапустите сборку — значения будут вшиты в APK.

## Сборка

APK собирается автоматически при каждом пуше в `main` (GitHub Actions) и публикуется в Releases → `latest`.
Локально: `./gradlew assembleRelease`, нужен Android SDK.
